# Quiet Table

Agentic restaurant booking prototype — UI-first wizard with conversational fallback.

## Local dev

```bash
npm install
cp .env.example .env.local
npm run dev -- --port 3003
```

Open [http://localhost:3003](http://localhost:3003).

## Deploy

**GitHub + Vercel (Hobby).** See **[DEPLOY.md](./DEPLOY.md)** for push, import, and env vars.
